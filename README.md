# Glow-Break

Glow-Break is a fast-paced **neon brick breaker** game inspired by classic arcade mechanics and modern mobile gameplay.

Shoot, bounce, and break glowing blocks while collecting power-ups and extra balls. Each turn increases the challenge, forcing you to plan your shots carefully to survive as long as possible.

Built with **pure HTML, CSS, and JavaScript**, Glow-Break runs directly in the browser and is optimized for both desktop and mobile devices.

🎮 **Features**
- Turn-based brick breaker gameplay  
- Neon visuals with particle effects  
- Multiple difficulty modes (Easy, Medium, Hard)  
- Power-ups: fireballs, lasers, bonus damage  
- Mobile & touch support  
- No external libraries  

🚀 **Play Online**
This project is hosted using **GitHub Pages**.  
Just open the link and play instantly — no downloads required.

🛠 **Tech Stack**
- HTML5 Canvas  
- Vanilla JavaScript  
- CSS3  

💡 **Goal**
Reach the highest turn possible before the bricks reach the bottom.
